# Ragers

Ragers is a CLI tool used for managing files in a repository who are meant to be encrypted when shared.

It is aimed for individual and teams who wish to collaborate in zero-trust environments.

**Ragers is open-source software**. Licensed under the GPLv3. Sponsoring is appreciated.

# Features

<div class="grid cards" markdown>

- :lucide-code: __Open-source__

    ---

    Ragers is open-source software, you can contribute, propose suggestions, and review the code.

- :lucide-shield-ban: __Based on `age`__

    ---

    Using `age` for encrypting your files, you are using the latest cryptographics solutions currently used. (WIP: support for post-quantum key will be supported whenever possible)

- :lucide-git-graph: __Git-friendly__

    ---

    Ragers come with a [git hook](/git-hook) to ensure you won't commit your files unencrypted.

- :lucide-zap: __Made with Rust, baby!__

    ---

    Written in Rust, your files are processed as quickly as humanly possible!
