# Install Ragers

Currently, Ragers is only available directly from source, by building it.

There exist no packages known for having published Ragers.

If you wish to install Ragers, you must use `cargo` to install it. If you do not know `cargo`, you must install Rust in your system to build Ragers.

Documentation is not yet provided on how to install Ragers. This will only be provided for 1.0, or if attraction for Ragers is given for me to care enough about it ASAP.
